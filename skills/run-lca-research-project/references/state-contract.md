# Research project state contract

## Source and projections

- `research-events.jsonl`: append-only, lossless project history and replay source.
- `project-snapshot.json`: complete current projection used for inspection and debugging.
- `machine-context.json`: compact active context for controller decisions.
- `human-status.md`: progressive explanation of objective, current stage, next step, risks, and terms.

Deleting any projection must not destroy research state. Running `status` rebuilds all projections from the event history.

## Project lifecycle convergence state

`research.lifecycle.*` in the same Research Kernel history is the single dynamic lifecycle truth. It does not create a parallel state store. Stable product architecture stays in `docs/council-default-product-architecture.json`; immutable acceptance and cutover outputs remain historical evidence and do not become live state.

The typed event family is:

- `research.lifecycle.control_plane_initialized`
- `research.lifecycle.goal_observed`
- `research.lifecycle.phase_started`
- `research.lifecycle.phase_ready_to_complete`
- `research.lifecycle.goal_completion_observed`
- `research.lifecycle.rollback_observed`
- `research.lifecycle.recovery_observed`

Legal durable states are `pending`, `in_progress`, `ready_to_complete`, `goal_completed`, `rollback_active`, and `recovered`. The reducer derives formal status and claim mode; payload authors cannot select them independently. A Goal observation is a point-in-time external fact with `observed_at`, platform source, expected thread and predecessor. It does not assert live access, and completion or absence is accepted only after the matching ready event.

`lifecycle-state.json`, lifecycle `human-status.md`, and repository `CONTEXT.md` are deterministic projections. The latter contains the compact recovery fields and exactly one route. `.superpowers/sdd/progress.md` is historical-only. Stable contracts must not copy current Goal identity, current date, active module, current claim set or route.

The finalizer runs the exact allowlisted gate set, stages and validates candidate bytes, registers content-addressed transcripts, manifest and receipt in the ready event, then rebuilds projections. A failed normal attempt appends no ready event. Same-key retry is idempotent; a retry after ready repairs derived files. The ready commit does not reference its own future SHA. Platform completion happens only after no required work remains, and a later observation reconciles the non-atomic boundary.

Rollback verifies exact Git `22d0576ad1a3f25ceef05ec5940fb02a848a27e9` and appends state; recovery appends a successor. It does not rewrite immutable acceptance, registered artifacts or TianGong facts, and neither transition deletes Council history.

Every event contains a sequence, unique event ID, UTC timestamp, actor, optional idempotency key, and typed payload. `research.scope.defined` binds the canonical scope to its original input, source path/hash, normalization changes, validation status, assumptions, and missing-data paths. A completed activity exposes only registered artifacts whose contents were hashed; replay verifies those hashes before returning the stored result and fails closed on missing or changed artifacts.

Every activity declares an effect. `external_write` and `irreversible` effects require a later human-authored `authorization.granted` event bound to the same request, activity, and effect before the subprocess can start. An authorization cannot be reused by another activity. Local work and external reads proceed autonomously; risk events do not block execution. Native command completion and Kernel semantic acceptance are separate: a rejected evidence, identity, build-plan, materialization, dataset-validation, or Process-QA report remains immutable under its attempt directory, and the same scientific input advances to a new attempt after either command failure or semantic rejection instead of reusing or overwriting the prior artifact. Exit-code and missing-output failures pin the execution report path, bytes, SHA-256, and command SHA-256 in `activity.failed`; a later attempt fails closed if that evidence drifted. Every input detail that can change a generated payload—including relative-versus-absolute CLI path semantics and the exact command prefix/executable identity—must enter the Activity identity.

## Continuous Research Director state

The Director adds no parallel truth. Its projection is derived from the same event log and Artifact Bus and is emitted as `director-status.json` only after a Director event exists; legacy Projects without Director history remain byte-compatible and do not acquire the file.

Internal instructions register `director_internal_packet` artifacts. Failed internal attempts register immutable `director_failure_observation` artifacts before retry, replan, reversible rollback, or dependent-branch parking. A human-owned boundary registers one `responsibility_handoff` artifact and appends `research.responsibility.handoff_prepared`; its payload binds the action, payload hash, scope, reason, resume route, zero-effect assertion, source work item, and current Council revisions. Replaying the same semantic input returns the same registered bytes and does not grow history.

The compact Director projection records the current work-item identity, route and revisions, the last directive, failure observations, handoff reference, accepted outcome, and exactly one resume or next route. `director_failure_observation` is evidence for deterministic routing, never a second activity log. Registered artifact drift, stale worker revisions, undeclared effects, and altered handoff payloads fail closed during replay and projection rebuild.

It is `formal_operational_truth` because the exact registered gate manifest and clean acceptance were accepted by `research.council.cutover_accepted`; a command or prompt alone still cannot promote a Project. The `council` projection is rebuildable and separate from the legacy `research_council` projection. Each event is Controller-authored after semantic replay, binds a content-addressed registered artifact where required, and preserves one next route. Agenda and Cell revisions reject stale worker results. Cell closure retains the incumbent, dissent, flip/reactivation conditions, or an explicit no-incumbent insufficient-evidence disposition. Deterministic fast-path results bind the same agenda, authority, source, effect, idempotency, and replay rules.

Cutover is valid only after every versioned product, runtime, Controller/Skill/state, Freshwater, 53-negative, fast-path, recovery, drift, stale, rollback, focused/full verification, zero-forbidden-effect, and clean-independent-acceptance gate has exact registered evidence. `council-accept-read-only` may observe a cutover-accepted state without appending or rematerializing it. Rollback is append-only, preserves all Council history, and binds exact commit `22d0576ad1a3f25ceef05ec5940fb02a848a27e9` plus the frozen Controller/Skill/state hashes.

Legacy `research.research_council.*` events retain their original experiment and A/B semantics for replay only. They never satisfy a formal cutover transition, and formal events never rewrite them.

## Experimental Research Council state

The Council uses the existing Project event log and Artifact Bus; it does not create a second truth system. Its seven durable event families are:

- `research.research_council.benchmark_qualified`
- `research.research_council.experiment_frozen`
- `research.research_council.cell_advanced`
- `research.research_council.trial_registered`
- `research.research_council.evaluated`
- `research.research_council.architecture_decided`
- `research.research_council.accepted`

Every Council event is valid only when its content-derived idempotency key matches its semantically recompiled payload, it contains exactly one `next_route`, exactly one content-addressed artifact descriptor under `research-council-benchmark/`, and a complete effect record whose prohibited counts are zero. The Kernel verifies artifact path confinement without symlinks, registered bytes and hashes, exact predecessor identities, and the entire Council event stream before materializing any view. A rejected event or logical fork leaves no artifact file.

The accepted lineage is fail closed. Qualification precedes one freeze. Cell successors bind the latest portfolio and cannot fork or advance after closure. Trial traces bind the freeze and remain isolated by arm. Evaluation is terminal for later trials and must be followed immediately by exactly one architecture decision. Acceptance requires that decision, a complete namespace inventory, semantic replay through the narrow Project port, and unchanged source bytes. Same-key repetition returns the existing event and artifact rather than growing history.

Council invalidation is content-addressed and scoped to the experiment. When an accepted experimental input changes, only its declared transitive descendants may become stale; earlier events and artifacts remain immutable. A competing freeze, portfolio successor, trial lineage, evaluation, or decision is a rejected fork rather than an in-place rewrite. A separately authorized experiment starts from a new isolated Project/freeze lineage. No Council invalidation changes the current TianGong Authority Receipt or formal Controller truth.

The compact projection contains only current status, qualification/freeze/cell/portfolio/trace/evaluation/decision/acceptance IDs as applicable, aggregate counts, recent artifact references, blocker, and one route. Worker transcripts, prompts, compiler rankings, gate scores, case details, result values, and role choreography remain outside machine context in registered artifacts. Human status explains the same state without becoming authority.

Replay validates the complete lossless event history, re-hashes every registered artifact, checks lineage and namespace isolation, and rebuilds `project-snapshot.json`, `machine-context.json`, and `human-status.md` deterministically. Recovery after projection deletion is replay from the event log; read-only acceptance performs the same semantic replay in a clean context and must not mutate source bytes, append unplanned events, or execute prohibited effects. The Council remains experimental until a later verified promotion decision is formally applied.

## Context policy

The event and artifact layers are lossless. The machine projection is deliberately lossy and rebuildable. It contains current routing state plus the 20 most recent artifact and decision references, their total counts, a full-snapshot pointer, and an event-history hash. Follow those pointers only when older evidence is needed. Human status explains rather than mirrors the machine schema.
