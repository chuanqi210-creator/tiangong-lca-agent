# Provider relationship evidence checklist

Use this checklist only after the provider-linkage method has been selected from
typed Project Record state.

- Identify each technosphere input by exact exchange identity and version.
- Record the asserted Provider identity, version, and the source location that
  states the relationship.
- Distinguish an explicit Provider relation from a name match, note, or inferred
  upstream supplier.
- Record unresolved inputs as typed missing Provider relations; never invent a
  connection to complete the graph.
- Report the checked-input denominator, the exact covered inputs, conflicts, and
  the resulting claim ceiling.

This resource is a deterministic review aid. It does not create TianGong facts,
expand permissions, or authorize a Project Record write.
