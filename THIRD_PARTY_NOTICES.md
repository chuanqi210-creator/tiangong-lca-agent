# Third-party notices

The clean public tree contains project-owned source and explicitly declared
synthetic structural fixtures. Redistribution-sensitive PDF, Office, archive,
audio, image, web-body, TIDAS, Project Record, Run Trace, and provider evidence
from the private archive are not included.

Language package dependencies remain identified by the committed Python and
Node lockfiles and retain their upstream licenses. Before a public release is
cut, the redistribution ledger must show no unresolved asset emitted into the
public tree. Source URLs, access times, hashes, and short lawful excerpts may be
retained when full source bodies cannot be redistributed.

The release process must regenerate this notice if an approved third-party
asset is added; an unknown or review-required emitted asset blocks publication.
